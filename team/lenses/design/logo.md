# Logo Design

Logo design is concept + typography + optical construction + system behavior.

## Choose mark type intentionally

Options:
- wordmark;
- lettermark;
- symbol;
- combination mark;
- responsive identity variants.

Do not force a standalone symbol when the name itself can carry a stronger identity.

## Concept process

### 1. Semantic territory
Start from:
- product mechanism;
- user transformation;
- name meaning/sound;
- domain tension;
- structural metaphor;
- distinctive letterform opportunity.

### 2. Concept families
Explore genuinely different mechanisms:
- custom wordmark;
- negative-space symbol;
- monogram;
- modular/system symbol;
- abstract mark with defensible concept;
- pictorial mark when category/context supports it.

### 3. Avoid cliché defaults
Challenge:
- sparkles;
- four-point AI stars;
- neural-node networks;
- infinity loops;
- generic hexagon;
- generic shield/check;
- arrow hidden in every letter;
- arbitrary letter inside a circle;
- meaningless gradient blob.

A cliché can be used only if transformed enough to become distinctive and relevant.

## Construction principles

Inspect:
- silhouette;
- positive/negative space;
- symmetry vs optical balance;
- stroke weight;
- counters;
- corner logic;
- curve quality;
- symbol/wordmark proportion;
- baseline;
- optical correction;
- kerning.

Geometrically perfect is not always optically correct.

## Wordmark

Evaluate:
- custom letter opportunities;
- kerning;
- rhythm;
- ambiguous letterforms;
- small-size recognition;
- personality match;
- international characters if relevant.

Do not simply type the company name in the selected UI font and call it a wordmark.

## Reduction test

Required checkpoints where relevant:
- 16px favicon;
- 24px;
- 32px;
- 64px;
- 128px;
- large format.

Test:
- black on white;
- white on black;
- grayscale;
- brand color;
- icon alone;
- wordmark alone;
- combination.

At small size:
- remove details that collapse;
- preserve silhouette;
- correct counters/spacing optically.

## Comparison board

When direction is open, show 3–5 concept families at low/medium fidelity before polishing one.

Keep presentation neutral enough that mockup glamour does not bias concept selection.

## Identity handoff

Once approved, define:
- primary lockup;
- secondary lockups;
- icon;
- monochrome;
- clear space;
- minimum size;
- background rules;
- misuse examples.

## Legal limit

Never state or imply trademark clearance based on design intuition.
Trademark search/legal review is separate.
