# Visual Design & Art Direction

## Hierarchy

Use:
- position;
- size;
- weight;
- contrast;
- whitespace;
- grouping;
- repetition;
- color;
- depth where meaningful.

Hierarchy should track decision importance.

If four KPIs have identical giant cards, the UI claims all four are equally important.

## Composition

Judge the page as one composition:
- first read;
- scan path;
- alignment axes;
- visual anchors;
- persistent chrome;
- content zones;
- rhythm;
- whitespace distribution;
- density.

Beautiful individual components do not guarantee a good page.

## Specificity

The interface should feel authored for its product.

Generic defaults to challenge:
- equal-weight KPI card row;
- giant rounded card for every section;
- floating pill navigation by default;
- gradient/glow as technology shorthand;
- decorative icon bubbles;
- arbitrary glass;
- oversized headings in operational products;
- excessive whitespace that lowers throughput;
- shadcn component catalog presented as product design.

These patterns are not banned. They need a product reason.

## Restraint

Every visual effect needs a job:
- grouping;
- hierarchy;
- affordance;
- status;
- brand expression;
- emotional tone.

Remove effects whose only rationale is "looks designed."

## Surface/material model

Define:
- page background;
- primary surface;
- raised/overlay surface;
- divider/border logic;
- shadow/elevation logic;
- radius logic.

Avoid nesting card inside card inside card.

## Iconography

Define:
- family;
- stroke/fill;
- weight;
- optical size;
- corner character;
- selected/active treatment.

Use text labels for unfamiliar critical actions.

## Imagery

Art-direct:
- subject;
- perspective;
- crop;
- color relationship;
- consistency;
- focal point;
- responsive behavior.

Do not fill whitespace with stock imagery.

## Motion character

Brand motion can be:
- precise/snappy;
- soft/springy;
- cinematic;
- mechanical;
- understated.

Interaction motion remains subordinate to usability.

## Craft pass

Zoom in:
- optical alignment;
- icon/text centering;
- baseline;
- corner consistency;
- 1px border rhythm;
- truncation;
- long labels;
- empty/loading alignment;
- hover/focus/pressed;
- contrast;
- real data.

Then zoom out:
- does the screen still have one dominant story?
