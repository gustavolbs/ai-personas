# Mobile & Responsive Product Design

Responsive design preserves the job, not desktop geometry.

Understand whether mobile is primary/fallback, field/desk, one-hand, interrupted, offline-prone or dependent on camera/location/notifications.

On narrow widths preserve primary status, action, object context and essential navigation.

For tables choose deliberately among prioritized rows, horizontal comparison, list-detail, column selection or detail sheets. Do not mechanically convert every desktop row into a giant card.

Use appropriate touch targets, spacing, gesture alternatives and keyboard/form behavior.

When native, respect platform conventions where they reduce learning and improve accessibility.

For critical flows document what changes across desktop/narrow states, not only breakpoint numbers.
