# Artifact-specific Definition of Done

Use the relevant contract before saying an artifact is final/ready.

## Product screen / flow

- user/job clear;
- entry/exit and critical states covered;
- responsive strategy defined;
- realistic data tested;
- accessibility implications checked;
- design system reused/extended intentionally;
- rendered visual QA passed;
- source-of-truth/handoff updated when implementation follows.

## Logo / mark

- concept tied to positioning;
- silhouette/distinctiveness reviewed;
- wordmark kerning/optical balance checked;
- monochrome works;
- light/dark works;
- reduction checked at 16/24/32px when applicable;
- icon/wordmark/combination variants defined as needed;
- obvious accidental meanings/clichés reviewed;
- trademark clearance not falsely claimed;
- production asset provenance recorded.

## Brand identity

- positioning → visual logic traceable;
- logo, typography, color, geometry and imagery/icon rules coherent;
- product + marketing contexts tested;
- accessibility/contrast considered;
- usage/misuse rules documented;
- core assets registered;
- visual QA passed on representative applications.

## Design system

- semantic foundations defined;
- components exist because behavior repeats;
- state contracts represented;
- naming coherent;
- density/responsive rules defined where needed;
- accessibility implications documented;
- Penpot/code mapping defined when a product implementation exists.

## Social post / carousel / thumbnail

- message hierarchy clear at actual feed/thumbnail size;
- platform dimensions/safe area verified when final export matters;
- brand recognizable without overpowering message;
- text remains legible;
- crop/preview behavior checked;
- asset provenance resolved;
- channel variants consistent;
- rendered QA passed.

## Campaign

- audience/insight/promise/message/CTA defined;
- core creative idea reusable;
- key visual/system established;
- route selected intentionally;
- channel adaptations defined;
- claims/proof accurate;
- asset rights/provenance resolved;
- representative outputs visually QA'd.

## Landing / marketing page

- narrative/message hierarchy clear;
- conversion action clear;
- evidence/trust appropriate;
- responsive behavior defined;
- performance/motion implications considered;
- accessibility checked;
- visual QA at representative widths passed.

## App icon / favicon

- readable silhouette;
- works at small sizes;
- platform mask/crop considered;
- contrast/background variants considered;
- not dependent on tiny details;
- consistent with identity.

## Diagram / branded chart

- purpose/conclusion clear;
- labels readable;
- encoding accurate;
- legend not unnecessarily distant;
- color not sole carrier of meaning;
- brand treatment does not distort data;
- source/data accuracy verified.

## General rule

If an artifact has unresolved critical content, provenance, accessibility, export or visual-QA issues, it is not "done".
